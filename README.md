# 都市·命途 — 都市人生重开模拟器

> **"天空永远是灰色的。26 个翼，26 座巢，无数后巷，64 亿人。你的一生，从这里开始。"**

《都市·命途》是一款基于浏览器运行的 **月亮计划（Project Moon）世界观** 人生重开模拟器。在由"首脑"统治、"翼"割据、"巢"与"后巷"极度割裂的都市（The City）中，从出生体验到"终结"的完整一生——最高可活 **150 岁**。

[▶ 在线游玩](https://Prorejm.github.io/city-fate/)

---

## 游戏特色

### 六维属性 · 25 点分配
体质、智力、直觉、意志、运道、共鸣——每一次分配，都在定义你在都市中的生存方式。

### 150 岁完整人生
1 回合 = 1 年。从后巷的啼哭到百岁寿辰，逐年推进，逐年记录。

### EGO / 扭曲 / 大罪 · 三条精神命运线
世界观机制核心：情绪积累 → 内心之声 → 叩问自我。
- **接受痛苦与罪孽** → 绽放 E.G.O（专属武装，如"血雾""终末之焰"）
- **只认痛苦、拒绝罪孽** → 扭曲（异变形态 + 被协会讨伐的风险）
- **全部拒绝** → 大罪化（傲慢/嫉妒/暴怒/倦怠/暴食/忧郁/色欲 七种终局）

### 都市生态
- 8 种出身：后巷耗子、巢内市民、应试村苦读生、郊区幸存者、血魔眷属……
- 收尾人九阶 → 一阶 → 色彩级 晋升线
- 五指帮派（拇指之礼 / 食指之信 / 中指之义）、十二协会、翼公司职场（L/T/N/K/J/M……）
- 历史大事件：白夜黑昼、钢琴家、烟霾战争、机械肃清之日、图书馆建立、边狱巴士启程
- 后巷深宵、禁忌、愿力赌场、异想体遭遇、金枝与星星

### 动态角色立绘
集成 [dynamic-avatar-drawer](https://gitlab.com/PerplexedPeach/dynamic-avatar-drawer)（LGPL v3）——角色随年龄、性别、身份、情绪、EGO/扭曲/大罪状态实时变化。

### 全局成就 + 多周目重开
60+ 成就跨周目永久解锁；死亡结算墓志铭、遗产点继承，轮回不止。

## 本地开发

```bash
npm install
npm run dev        # 开发模式 http://localhost:5173
npm run build      # 生产构建（tsc + vite）
npm run preview    # 预览构建产物
npm test           # vitest 单元测试
npm run validate:data   # 游戏数据校验
```

## 技术栈

React 18 · TypeScript · Vite 5 · Tailwind CSS 3 · Zustand（持久化键 `cityFateData`）· Vitest
